# 🦖 Ensiklopedia Grup Digimon

Website sederhana yang memuat daftar dan penjelasan singkat mengenai berbagai grup dan faksi terkenal dalam dunia Digimon.

## 🚀 Fitur
- **Responsif**: Tampilan nyaman dibuka lewat HP maupun Desktop.
- **Live Search**: Cari nama grup atau anggota Digimon secara instan.
- **Desain Modern**: Menggunakan tema warna *dark mode*.

## 🛠️ Teknologi
- HTML5
- CSS3
- JavaScript (Vanilla)
